# raylib-based canvas for ROOT

This is experimental implementation of `TCanvasImp` class with use of raylib

   * It only works with single canvas
   * It has very limited interactivity features
   * It does not support different ROOT fonts - especially symbols.ttf for greek letters

Just prove of principles that painting and mouse event handling can be performed in absolutely
new environment.

If there is interest to continue this project - contact authors.
